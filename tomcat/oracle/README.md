# Oracle JDK 8u202 build input

Place the account-authenticated Oracle archive here as:

`jdk-8u202-linux-x64.tar.gz`

The archive is intentionally ignored by Git. Record its SHA-256 in
`ORACLE_JDK8_SHA256`, accept the Oracle BCL explicitly, and use the Oracle
Tomcat build only after reviewing the redistribution terms. The supported
Oracle compatibility image is Linux AMD64, Tomcat 9 and JDK 8u202.

OneinStack does not download, publish or provide the Oracle binary.
